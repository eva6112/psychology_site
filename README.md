# Сайт-визитка психолога: Татьяна Голощапова

##  О проекте
Сайт разработан как мобильно-ориентированный лендинг для профессиональной презентации услуг психолога. 

**Основные разделы:**
- *Обо мне:* профессиональное позиционирование и специализация.
- *С чем я помогаю:* основные направления работы.
- *Методы* подробный обзор инструментов.
- *Консультации:* структурированные форматы работы с описанием цен и условий.
- *Связь:* быстрый доступ к Telegram и Instagram.

##  Технологический стек
Проект реализован с использованием классического стека веб-технологий:
*   *HTML* — семантическая структура документа.
*   *CSS3* — адаптивная верстка.
*   *JavaScript* — логика взаимодействия пользователя с элементами интерфейса.

##  Дизайн-система
*   *Шрифт:* Nunito (дружелюбный и современный стиль).
*   *Адаптивность:* Mobile-First подход (оптимизировано под экраны смартфонов).
